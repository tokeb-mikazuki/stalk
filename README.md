# 공포의 채널유기

![타이틀](assets/screenshot_title.jpg)

끝없이 이어지는 나선형 계단을 1인칭으로 올라 **옥상 문**까지 탈출하는 3D 추격형 공포 게임입니다.
엘리베이터를 타고 아무 층에나 내려 계단을 따라 다가오는 존재, **피구공**을 피해야 합니다.

원작 `reference/Stalker.html`(2D 진행 바 게임)의 아이디어를 3D로 재구성했습니다.

## 실행 방법

| 방법 | 설명 |
|---|---|
| 바로 실행 | `dist/index.html` 을 브라우저(Chrome / Edge / Firefox / Safari)로 엽니다. 파일 하나에 코드·이미지가 모두 들어 있어 서버가 필요 없습니다. |
| 개발 모드 | `npm install` → `npm run dev` → <http://localhost:5173> (저장하면 자동 재빌드) |
| 빌드 | `npm run build` → `dist/index.html` 생성 |
| 안드로이드 | `dist/channel-yugi.apk` 를 폰에 받아 설치합니다 (알 수 없는 앱 설치 허용 필요). 상태바·내비게이션 바 없는 전체 화면, 가로 고정, 화면 꺼짐 방지. 뒤로 가기: 게임 중 일시정지 / 메뉴에서 한 단계 뒤로 / 타이틀에서 앱 내리기 |
| APK 빌드 | `npm run apk` (JDK 17+ 와 Android SDK 필요 — `ANDROID_HOME` 또는 `android/local.properties`) → `dist/channel-yugi.apk`. 앱 소스는 `android/` (WebView 하나에 `dist/index.html` 을 담는다). 업데이트 설치가 되도록 서명 키 `android/app/songshin-release.jks` 를 저장소에 함께 둔다 |

PC(키보드 + 마우스)와 모바일(터치) 모두 지원합니다. 이어폰/헤드폰 착용을 권장합니다 (입체 음향).

## 조작법

| PC | 모바일 | 동작 |
|---|---|---|
| `W` `A` `S` `D` | 왼쪽 화면 가상 조이스틱 | 앞 · 왼쪽 · 뒤 · 오른쪽 이동 (보는 방향 기준) |
| 마우스 | 오른쪽 화면 드래그 | 시점 회전 |
| `Shift` | 달리기 버튼 / 조이스틱 끝까지 | 달리기 (체력 소모) |
| `C` / `Ctrl` | 숙이기 버튼 | 웅크리기 (조용히 이동) |
| 마우스 우클릭 / `F` | 손전등 버튼 | 손전등 켜기/끄기 |
| `E` / 마우스 좌클릭 | 조사 버튼 | 줍기 · 쪽지 읽기 · 문 여닫기 · CCTV 보기 · 엘리베이터 호출 |
| `Esc` / `P` | II 버튼 | 일시정지 |

설정: 마우스 감도, Y축 반전, 음량, 밝기(감마), 그래픽 품질(낮음/보통/높음/울트라), 음성 연출(브라우저 TTS).
그래픽 품질은 처음 실행할 때 GPU를 보고 자동으로 고릅니다.

## 게임 규칙

- **목표**: 꼭대기 층 옥상 문을 열고 탈출한다. 한 층은 나선 두 바퀴(걸어서 약 15초)다.
- **피구공**: 엘리베이터를 타고 플레이어가 있을 것 같은 층(주로 그 위층)에 내려, 자기가 걷는 방향을 바라보며 계단을 따라 다가온다. 걷는 것보다 빠르고 달리는 것보다 느리다.
- **피구공의 감각 (짐작)**: 피구공은 플레이어의 정확한 위치를 모른다. 발소리(달리기 > 걷기 > 웅크리기, 멈추면 무음)·가까운 인기척·손전등 불빛으로 **몇 층쯤 위/아래인지**만 오차를 섞어 짐작하고 그쪽으로 간다. 짐작한 곳에 아무도 없으면 두리번거리다 떠난다. 문을 닫고 비상실에 숨었거나 엘리베이터 안이면 아무것도 느끼지 못한다. 피구공 자신도 엘리베이터에 타서 **문이 닫히는 순간부터 다시 걸어 나올 때까지는 바깥을 전혀 느끼지 못한다**(그 사이 비상실에서 나와도 들키지 않는다). 눈으로 보면 그때부터 추격.
- **엘리베이터 표시기**: 실제 엘리베이터의 현재 층과 방향을 보여준다. 가끔 숫자가 뒤죽박죽(글리치)이 된다.
- **기척**: 피구공이 엘리베이터에서 내리면 "계단에 누군가 있는 것 같다", 타면 "계단에 인기척이 느껴지지 않는다"가 붉은 글씨로 뜬다.
- **엘리베이터**: 실제로 오르내리는 한 대를 피구공과 함께 쓴다. 실제 엘리베이터처럼 움직인다 — 피구공이든 플레이어든 **먼저 부른 쪽으로 먼저** 가고, 가는 길에 같은 방향 호출이 있으면 들렀다 가며, 서서히 가속·감속하고, 반대로 가려면 먼저 멈춘다. 닫히는 중에 그 층 버튼을 누르면 다시 열린다. 피구공도 호출 버튼을 누르고 기다려야 탈 수 있어서, 엘리베이터를 다른 층으로 불러 두면 피구공은 한참 기다리다 계단으로 간다.
- **피구공이 탄 엘리베이터를 부르면**: 피구공이 누른 층 버튼은 취소되고, 엘리베이터는 플레이어가 부른 층에 선다 — 문이 열리면 피구공이 거기서 내린다. …엘리베이터에 직접 타는 것은 권하지 않는다.
- **층 표시 없음**: 지금 몇 층인지는 벽에 칠해진 층 번호로만 알 수 있다.
- **비상실 (숨을 곳)**: 매 판 시작할 때 **전체 층의 딱 절반**만 열려 있다(1층은 항상 잠김, 위아래로 고르게 흩어짐). 비상구 표시등이 켜진 비상문으로 들어가 문을 닫으면 피구공은 들어오지 못하고 문 앞을 서성이다 떠난다.
- **CCTV**: 비상실 모니터로 **모든 층**의 비상문 앞을 볼 수 있다. 처음엔 지금 층, `A`/`D`·`←`/`→`·마우스 휠로 층 이동, `Space`(또는 `Tab`)로 **전체 층 한 화면** ↔ 한 층 전환, 전체 화면에서 방향키로 고르고 `Enter`. 피구공이 비치면 `● MOTION`. `E`/클릭으로 끈다.
- **숨기 페널티**: 같은 층에 너무 오래 있으면 조명이 깜빡이며 경고하고, 곧 피구공이 찾아온다. 숨어 있었다면 CCTV에 문 앞으로 쓱 다가오는 모습이 비치고, 곧 문을 부수고 들어온다. 단, 피구공이 바로 위·아래 층(±1) 안에 있거나 문 앞을 막고 있는 동안은 체류 시간이 흐르지 않는다 (악몽은 예외 — 피구공이 가까이 있어도 흐른다).
- **청각과 시각**: 달리면 발소리가 멀리 퍼지고, 손전등을 켜 두면 멀리서도 눈에 띈다. 손전등을 끄면 눈앞밖에 보이지 않는다.
- **손에 든 손전등과 숨소리**: 빛줄기는 걸음마다 손을 따라 흔들리고(달리면 크고 거칠게), 고개를 돌리면 한 박자 늦게 따라오며, 피구공이 가까우면 손이 떨린다. 숨소리는 평소엔 코로 조용히, 달리고 나면 입으로 거칠고 빠르게 헐떡이다 천천히 가라앉고, 무서우면 떨리며, 숨어 있는데 피구공이 문 너머에 있으면 숨을 죽인다.
- **넘어짐**: 계단을 오래 달리거나, 체력이 바닥난 채 달리려 하면 넘어진다. 일어나는 데 시간이 걸린다.
- **높이**: 위로 올라갈수록 피구공의 시야·청각과 엘리베이터가 플레이어 쪽으로 올 확률이 아주 조금씩 높아진다.
- **악몽 모드의 열쇠**: 옥상 문이 잠겨 있다. 열쇠는 매 판 **엘리베이터 칸 안쪽 구석**(칸을 따라 움직인다 — 깊숙이 들어가 줍고 문이 닫히기 전에 바로 나와야 한다) 또는 **25~30층 열린 비상실 중 한 곳의 모니터 책상 위**에 있다. 시작할 때 안내 방송이 알려 준다.
- **엘리베이터 함정**: 칸 안에 탄 채 문이 닫히면 최소 10초(10~13초) 동안 움직인 뒤 문이 열리고, 피구공이 기다리고 있다.
- **엘리베이터**: 헤어라인 스테인리스 문·문틀, 오른쪽 문짝의 세로 유리창(실제로 비쳐 보여 지나가는 칸이 보인다), 거울·격자 조명·조작반이 있는 칸 내부.
- **탈출 엔딩**: 옥상 문을 열면 빛이 쏟아지고, 해 뜨는 옥상으로 걸어 나간다 — 판상형 아파트 단지와 아침 안개 속 도심, 강 위로 떠오르는 해, 새 떼, 깜빡이는 항공 장애등. 화면은 흑백에서 따뜻한 색으로 돌아오고, 메인 화면의 자장가가 이번엔 어긋남 없이 끝까지 흐른다.
- **FOUND YOU 뒤**: 피구공이 문을 부술 수 있는 사냥은 들킨 그 층에서만 유효하다. 다른 층으로 옮기는 데 성공하면 피구공은 관심을 잃고 사라진다.
- **디버그 패널**: 게임 중 `↑ ↑ ↓ ↓ ← → ← → B A` (또는 Pause 키 5번, 모바일은 일시정지 화면의 'PAUSED' 를 빠르게 5번 탭). 원하는 층으로 이동, 즉시 탈출, 무적·피구공 정지·피구공 숨기기, 체력·배터리 무한, 게임 속도(0.25~3배), FOUND YOU·피구공 호출·멀리 보내기, 비상실 모두 열기, 난이도·도전과제 해금, 진행 초기화, 실시간 상태(피구공 상태·짐작·엘리베이터).
- **자동 클리어 AI** (디버그 패널): 켜면 AI 가 대신 플레이한다 — 손전등을 끄고 조용히 오르다가, 피구공이 다가오면 먼저 닿을 수 있는 비상실로 숨거나 위에서 내려오면 등을 돌려 달아나고, 악몽에서는 열쇠(비상실 책상 / 엘리베이터 안)를 챙겨 옥상으로 나간다. 들키지 않는 것을 최우선으로 — 피구공이 보이면 피구공보다 먼저 닿는 비상실에 조용히 숨고, 같은 층 체류 한계 전에 층 경계를 넘나들어 시간을 되돌리며, 피구공이 탄 엘리베이터가 오면 문 앞을 피한다. 늘 이기지는 못한다.
- **안내 방송**: 건물 천장 스피커 같은 목소리(트레일러와 같은 TTS)가 안내 문구를 읽어 준다. 처음에는 친절한 안내였다가, 쫓기거나 들키면 일그러진다. 설정 → '안내 방송 음성'으로 끌 수 있다(글자는 그대로).
- **메인 화면 음악**: 자장가 오르골과 따뜻한 화음이 바퀴를 돌 때마다 조금씩 늘어지고 어긋난다.
- **일시정지**: 30초 넘게 멈춰 있으면 화면이 깨지고 "숨을 수 없다" — 피구공이 바로 뒤에서 쫓아온다.

## 화면 · 사운드

- 주의 문구 → 실제 진행률이 표시되는 로딩 화면(팁) → "아무 키나 누르세요" → 메인 메뉴
- 메인 메뉴 · 난이도 카드 · 도전과제 · 설정 · 일시정지 · 결과 화면 (키보드 ↑↓ / Enter / Esc 지원, 메뉴 효과음)
- 발소리(뒤꿈치·앞꿈치, 계단/계단참/방 표면, 계단실 메아리), 넘어짐(미끄러짐·충돌·손전등 구르는 소리·신음), 수신기 무전 잡음과 일그러진 목소리
- 안내 문구는 처음 한 번만 표시 (설정에서 다시 보기)

## 그래픽

- 노멀맵(타일 줄눈·콘크리트 요철)과 거칠기맵(타일 광택)을 코드로 생성
- HDR 렌더링 + 블룸(전등·비상구 표시등·엘리베이터 표시기 빛 번짐)
- 손전등 빛줄기(볼류메트릭 콘)와 빛 속에 떠다니는 먼지 입자 (GPU 셰이더)
- 손전등 그림자, MSAA, 이방성 필터링
- 흑백 필름 톤, 그레인, 색수차, 글리치, CCTV(어안·주사선) 후처리

## 프로젝트 구조

```
index.html          HTML/CSS (HUD, 메뉴, 터치 UI) — 빌드 시 스크립트가 인라인됨
src/
  main.js           게임 루프, 상태 전환, 상호작용, CCTV, 아이템, 품질 설정
  config.js         계단 수학(나선 좌표, 비상실 로컬 좌표), 난이도
  world.js          나선 계단 타워 생성 (계단, 난간, 벽, 엘리베이터, 비상실, 조명)
  player.js         1인칭 이동, 비상실 출입 충돌, 스태미나, 손전등, 넘어짐
  stalker.js        피구공 AI (엘리베이터/접근/배회/추격/수색/소멸)
  director.js       공포 이벤트, 숨기 페널티, 조명 깜빡임
  achievements.js   도전과제 · 진행 저장
  touch.js          모바일 가상 조이스틱 · 터치 시점 · 버튼
  fx.js             손전등 빛줄기 · 먼지 입자 셰이더
  audio.js          Web Audio 절차적 사운드 (오디오 파일 없음)
  post.js           블룸 + 필름 톤 + CCTV 후처리 셰이더
  textures.js       캔버스 절차적 텍스처 · 노멀맵 생성
  hud.js            HUD / 화면
assets/songsin.png  피구공 스프라이트 (배경 제거본)
assets/src/         원본 이미지 (피구공 원본, 계단 참고 이미지)
tools/build.mjs     esbuild 단일 파일 빌드
tools/cutout.py     피구공 이미지 배경 제거 스크립트
reference/          원작 HTML
```

사용 기술: [three.js](https://threejs.org/) 0.170, esbuild. 모든 소리와 텍스처는 코드로 생성합니다.
